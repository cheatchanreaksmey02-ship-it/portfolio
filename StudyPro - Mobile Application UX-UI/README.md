# StudyPro — Mobile Application UX/UI

A UI/UX design for an online learning mobile app, connecting students with mentors for course-based learning. Designed in Figma, covering the full app experience — onboarding, browsing courses and mentors, lessons, payments, and profile management.

## Screens included

53 screens covering:

- **Onboarding & Auth** — launch screen, intro, register/login, forgot password, PIN setup
- **Home & Discovery** — home feed, categories, search, popular courses, mentors list
- **Courses & Mentors** — course details, curriculum, mentor profiles and ratings, reviews
- **My Courses** — ongoing, completed, lessons, video playback, certificates
- **Payments** — payment methods, transactions, e-receipts, add card
- **Inbox** — chats, voice calls, messages
- **Profile & Settings** — edit profile, notifications, security, language, invite friends
